# HASLAB compiler

The compiler area now executes pinned YOLOv8n nodes 0–136 through the complete backbone and both top-down neck C2f stages. It validates fused `Conv → Sigmoid → Mul` patterns, 1×1 and 3×3 stride-one/stride-two convolutions, residual and non-residual C2f blocks, zero-allocation split views, scaled channel concat, the exact three-pool SPPF pattern, and the pinned nearest-neighbor 2× Resize profile. It selects the largest legal divisor tile that fits input SRAM, supplies `-128` MaxPool border halos, preserves long-lived skip tensors, and streams weights or utility parameters when a complete set exceeds its local SRAM.

The implementation lives in `haslab_compiler/`. `hxb.py` writes the sectioned container proposed by the v0 contract, `vertical_slice.py` retains the initial one-tile proof, `first_layer.py` retains the complete first-layer proof, `pipeline.py` implements sequential layer planning, `c2f.py` supplies calibrated branch operations, and `graph.py` defines the reusable IR and lifetime allocator. Diagnostic packages retain every material boundary for differential checks. Release packages use deterministic first-fit allocation over inclusive operation lifetimes and expose only declared final outputs. Identical inputs produce byte-identical packages. The [reusable graph format note](reusable-graph-format.md) records the latest schedule and evidence.

This is not yet a general ONNX compiler. The reusable IR currently receives validated specs extracted through both pinned top-down neck stages; it does not yet import the bottom-up neck and learned heads, emit the INT32 learned-head boundary, or execute the declared host tail. The experimental manifest schema is intentionally narrow and must be reviewed before it becomes a stable package interface.

Run the source-independent compiler tests through `make test`. Reproduce the pinned real-model layer in the workload guide under `benchmarks/manifests/yolov8n-320-opset13/`.
