# Compiler

The compiler area executes pinned YOLOv8n accelerator nodes 0–217 through the three learned detection-head boundaries. It validates fused `Conv → Sigmoid → Mul` patterns, raw output convolutions, 1×1 and 3×3 stride-one/stride-two convolutions, residual and non-residual C2f blocks, zero-allocation split views, scaled INT8 channel concat, exact INT32 channel concat, the three-pool SPPF pattern, and nearest-neighbor 2× Resize. It selects legal SRAM-fit tiles, supplies `-128` MaxPool border halos, preserves long-lived neck skips, streams weights or parameters that exceed local SRAM, and emits raw biased INT32 accumulators with exact per-channel dequantization scales.

`haslab.graph-schedule.v1` supports diagnostic allocation, which retains every materialized boundary for differential checks, and deterministic release allocation, which reuses storage after inclusive lifetimes end. The current learned-head report records exact agreement for 6,931,200 diagnostic values and all 302,400 release boundary values. See [the reusable graph format](reusable-graph-format.md) and [the tracked report](../benchmarks/manifests/yolov8n-320-opset13/m6-through-detection-head.json).

This is not yet a general ONNX compiler. The importer recognizes one pinned graph and the declared host detection tail at nodes 218–260 is not yet executed. The package schema remains experimental. Current packages are roughly 75 MB because commands and relocations are uncompressed; command delivery and package compaction must be resolved before the transport-facing ABI or interface RTL is frozen.
